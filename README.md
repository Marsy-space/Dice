# Dice
План разработки игры "Игра в кости/Шлеф" на Python/PyQt
1. Описание игры
- Цель: Игроки должны закрыть все числа на своей карточке (от 1 до 12), используя результаты броска двух костей.  
- Механика:  
  - Каждый игрок бросает две кости.  
  - Можно закрыть:  
    - Отдельные числа (например, выпало 3 и 5 → можно закрыть 3 или 5).  
    - Сумму чисел (3 + 5 = 8 → можно закрыть 8).  
  - Если нельзя закрыть ни одно число, ход пропускается.  
  - Побеждает тот, кто первым закроет все числа.  
---
2. Технический стек
- Язык: Python  
- Графический фреймворк: PyQt6 (для GUI)  
- Дополнительно: random (для броска костей)
